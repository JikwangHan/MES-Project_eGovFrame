# PR-05: UI 에러 메시지 템플릿(초안)

## 목적
- 화면별 오류 안내 문구의 기준을 통일한다.
- 사용자 혼선을 줄이고 운영 대응을 쉽게 한다.

## 공통 템플릿
- 입력 누락: "필수 입력 항목을 확인해 주세요."
- 형식 오류: "입력 형식을 확인해 주세요."
- 중복 오류: "이미 등록된 항목입니다."
- 조회 없음: "조회 결과가 없습니다."
- 시스템 오류: "일시적인 오류입니다. 잠시 후 다시 시도해 주세요."

## 화면별 확장(예시)
- 로그인 실패: "아이디 또는 비밀번호가 올바르지 않습니다."
- 권한 부족: "접근 권한이 없습니다."

## 비고
- 실제 문구는 UX 가이드 확정 후 조정한다.
