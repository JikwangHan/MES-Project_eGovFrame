# PR-05: UI 스캐폴딩 계획(초안)

## 목표
- UI/UX 설계 문서에 포함된 모든 화면을 기본 제공 대상으로 확정한다.
- 공통 레이아웃/메뉴/라우팅/빈 화면을 선행 구축해 화면 골격을 고정한다.
- 데이터 연결은 계약(API 스펙)만 합의하고 실제 바인딩은 후속 PR로 분리한다.

## 범위
- 공통 레이아웃: 헤더/사이드 메뉴/푸터 기본 제공
- 라우팅: 화면 ID 기준으로 고정(문서 화면 목록과 1:1 매핑)
- 공통 UI 패턴: 그리드, 상세/목록 분할, 검색 필터, 팝업 기본 골격

## 제외
- 실제 데이터 바인딩, 저장, 조회 로직
- 권한별 화면 제어(후속 PR에서 계약 확정 후 반영)

## 산출물
- 화면 목록 체크리스트
- 기본 레이아웃과 빈 화면 스캐폴딩
- UI 스모크(라우팅 200 또는 화면 렌더 PASS 라인)

## 검증(PASS 기준)
- 모든 화면 라우팅이 에러 없이 접근 가능
- 최소 스모크 스크립트 1개에서 PASS 라인 출력
