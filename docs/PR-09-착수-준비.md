# PR-09: 착수 준비(초안)

## 목적
- IoT 인터페이스(Edge Gateway)와 제조장비 간 1차 연동 준비를 확정한다.

## 범위(초안)
- 장비/프로토콜 미확정 상태에서 사용할 수 있는 공통 수신 흐름을 만든다.
- 입력 소스(파일/표준입력)를 통해 원시 데이터를 수신하고 저장/전송 로그를 남긴다.

## 전제 조건(확정 필요)
- 대상 장비/프로토콜/데이터 포맷은 추후 확정한다.
- 확정 시 전용 어댑터를 추가하는 것을 전제로 한다.

## 제외(초안)
- AI 자동 식별/파싱 로직은 PR-10 이후로 분리한다.
