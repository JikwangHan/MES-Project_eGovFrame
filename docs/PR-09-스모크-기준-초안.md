# PR-09: 스모크 기준(초안)

## PASS 기준
- GET /health 200
- (수신) 입력 소스(파일/표준입력) 기반 업링크 1건 이상이 수신된다.
- (저장) 수신 원시 데이터가 저장된다.
- (표준 로그) [PASS] 라인으로 수신/저장 결과가 출력된다.

## FAIL 기준
- 기동 실패 또는 /health 200 미응답
- 수신 데이터 0건
- 저장 실패

## SKIP 기준
- 대상 장비/프로토콜 미확정 시 장비 연동 검증은 [SKIP]
