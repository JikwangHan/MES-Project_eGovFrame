# 서비스별 Chat 연계(연동)용 Chart 설정(초안)

## 목적
- 서비스별 Chat 간 연동 상태를 공통 Chart로 관리한다.

## Chart 목록(초안)
- CH-01: 서비스별 PR 진행률
- CH-02: 스모크 PASS/FAIL 추이
- CH-03: 연동 API 계약 변경 이력
- CH-04: 장애/이슈 처리 상태

## Chart 입력 항목(공통)
- 서비스명: IoT/미들웨어/MES Web
- PR 번호
- 상태: 진행중/완료/보류
- 마지막 업데이트 날짜
- 담당 Chat

## 표준 표시 규칙
- 상태 색상: 진행중(노랑), 완료(초록), 보류(회색)
- 스모크 결과: PASS/FAIL/SKIP만 표시

## 비고
- 실제 Chart 도구는 추후 확정
