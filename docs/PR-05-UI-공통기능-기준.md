# PR-05: UI 공통 기능 기준(초안)

## 목적
- 모든 서비스에 공통으로 적용될 검색/차트/그리드/레포팅 기준을 정리한다.

## 공통 적용 원칙
- 검색: 기본/상세 검색을 제공하고 기간 필터를 포함한다.
- 차트: 가능한 서비스는 시계열/비교 차트를 제공한다.
- 그리드: 목록 화면은 표준 그리드를 사용한다.
- 레포팅: 가능한 서비스는 PDF/CSV 등 다운로드를 제공한다.

## 최소 기능
- 검색: 키워드 + 기간
- 차트: KPI/대시보드/품질/설비는 필수
- 그리드: 모든 목록 화면 필수
- 레포팅: KPI/품질/설비/재고 우선 적용
