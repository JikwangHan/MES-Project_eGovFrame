# 의존성 다운로드 설정

이 문서는 eGovFrame 의존성 다운로드가 막힐 때 바로 적용하는 기준입니다.
민감 정보는 포함하지 않으며, 실제 사내 주소는 별도 문서로 관리합니다.

## 1) 공식 eGovFrame 저장소 (외부 직접)
- 공식 URL: `https://maven.egovframe.go.kr/maven/`
- 이 주소는 `pom.xml`에 박지 않고 `settings.xml`에서 미러로 설정합니다.
- eGovFrame 4.0.x 이후 실행환경 좌표는 `org.egovframe.rte` 그룹을 사용합니다.

## 2) 사내 Nexus(권장)
- 사내 Nexus에 아래 2개를 Proxy로 만들고 Group Repo로 묶습니다.
  - Maven Central
  - eGovFrame 공식 저장소
- 개발자는 Group Repo URL 1개만 사용하도록 설정합니다.

## 3) settings.xml 예시 (사내 주소는 치환)
Windows 위치: `%USERPROFILE%\.m2\settings.xml`  
Linux 위치: `~/.m2/settings.xml`

```xml
<settings xmlns="http://maven.apache.org/SETTINGS/1.0.0"
          xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
          xsi:schemaLocation="http://maven.apache.org/SETTINGS/1.0.0 https://maven.apache.org/xsd/settings-1.0.0.xsd">
  <mirrors>
    <mirror>
      <id>nexus</id>
      <mirrorOf>*</mirrorOf>
      <url>http://[사내Nexus도메인]:[포트]/repository/maven-public/</url>
    </mirror>
  </mirrors>
</settings>
```

## 4) 적용 원칙
- 의존성 저장소는 `pom.xml`이 아닌 `settings.xml`에서 통제합니다.
- 버전 업그레이드가 필요하면 상위 `pom.xml`의 속성만 변경합니다.
