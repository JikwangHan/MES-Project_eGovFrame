# PR-01 계약 정리

## 목표
- 계약(Contract)과 테스트 이식 원칙을 문서로 고정한다.
- PR-02/PR-03 구현에 앞서 기준을 합의한다.
- 제조장비 -> MES Web 직접 연동과 IoT 인터페이스 -> MES Web 연동을 모두 포함한다.

## 산출물
- API 계약: `mes-contracts/src/main/resources/contracts/api-contracts.md`
- 오류 코드: `mes-contracts/src/main/resources/contracts/error-codes.md`
- 서명/정규화: `mes-contracts/src/main/resources/contracts/signature-and-normalize.md`
- 스모크: `scripts/smoke-contracts.ps1` 또는 `scripts/smoke-contracts.sh`

## 추가 기준
- 데이터 연동은 프로토콜 정의서에 따라 수행한다.
- 프로토콜 정의서는 추후 확정하며, 다수의 프로토콜을 지원할 수 있다.

## 검증 기준
- 스모크 실행 결과가 [PASS] 1줄을 출력한다.
