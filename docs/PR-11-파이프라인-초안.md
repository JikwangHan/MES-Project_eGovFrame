# PR-11: 파이프라인 구성(초안)

## 목적
- 원본 수신부터 분류/정규화 저장까지의 최소 흐름을 정의한다.

## 단계(초안)
1. raw 수신: 원본 payload 저장
2. 분류: text/json/csv/binary/unknown 판단
3. 파싱: 분류 결과에 따른 파서 선택
4. 정규화: 공통 스키마로 변환
5. 저장: normalized_event 저장
6. 실패 처리: 검증 실패 시 quarantine 이동

## 동시성 고려(초안)
- 동일 시점에 다수 수신을 처리할 수 있도록 원본 저장/정규화는 독립 처리한다.
- 큐 기반 처리 또는 비동기 실행을 고려한다.
