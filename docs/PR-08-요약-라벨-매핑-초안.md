# PR-08: 요약 라벨 매핑(초안)

## 목적
- 최근 조회 조건 요약에 사용되는 키를 사용자 친화적 라벨로 변환한다.

## 매핑
- orderId → 수주번호
- partnerName → 거래처명
- dueFrom → 납기일 시작
- dueTo → 납기일 종료
- status → 상태
- jobId → 작업 ID
- processName → 공정명
- from → 기간 시작
- to → 기간 종료
- name → KPI명
- kpiId → KPI ID

## 표시 순서(초안)
- 수주번호 → 거래처명 → 납기일 시작 → 납기일 종료 → 상태
- 작업 ID → 수주번호 → 공정명 → 기간 시작 → 기간 종료 → 상태
- KPI명 → KPI ID → 기간 시작 → 기간 종료

## 표시 정리 규칙(초안)
- 앞/뒤 공백 제거
- 연속 공백은 1칸으로 축약
- `<`, `>`, `"` 문자는 제거
- 비어 있는 값(빈 문자열/공백만/특수문자 제거 후 빈 값)은 요약에서 제외
- 12자 초과 시 말줄임표(...) 처리
- 요약 항목은 최대 4개까지 표시
- 4개를 초과한 항목은 "외 n건"으로 표시

## 전체 표시 조건(초안)
- 모든 필터 값이 비어 있으면 `최근 조회 조건: 전체`로 표시한다.
