# PR-08: UI 데이터 바인딩 설계(초안)

## 목적
- MES Web 화면에서 API 데이터를 안전하게 표시하는 최소 구조를 확정한다.
- DB 연동 전에도 화면/스모크 기준을 통과할 수 있게 한다.

## 바인딩 흐름(초안)
1) UI 페이지 로드
2) 브라우저가 `/api/*`를 호출
3) 응답의 `data` 배열을 테이블에 바인딩
4) 데이터가 없으면 "데이터 없음" 메시지 출력

## 적용 화면(우선)
- /ui/kpi
- /ui/orders
- /ui/jobs

## 바인딩 규칙(초안)
- API 실패 시 화면이 깨지지 않도록 "빈 상태"를 유지한다.
- `data`가 없거나 배열이 아니면 빈 목록으로 처리한다.
- 민감정보는 화면에 표시하지 않는다.

## 확장 방향(후속)
- 차트 라이브러리 연결(ECharts 등)
- 그리드 기능(정렬/필터/페이지네이션)
- 서버사이드 템플릿(Thymeleaf/JSP) 또는 SPA 전환 검토
