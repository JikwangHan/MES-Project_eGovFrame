# PR-08: UI 오픈소스 선정안(초안)

## 목적
- eGovFrame 환경에서 사용 가능한 무료 오픈소스를 확정한다.
- 차트/그리드/보고서/UI 템플릿의 후보를 미리 정리한다.

## 후보(무료 오픈소스)
- 차트: Apache ECharts (Apache-2.0)
- 그리드: Tabulator (MIT)
- UI 템플릿: JSP(기본)
- 보고서: JasperReports Community (Apache-2.0)

## 선정 기준(초안)
- 라이선스: 상업적 사용 가능
- eGovFrame와의 호환성(순수 HTML/JS 연동 가능)
- 커뮤니티/문서 안정성
- 장기 유지보수 용이성

## 제안(확정)
- 1순위: ECharts + Tabulator + JSP
- 보고서는 PR-05 범위에서 별도 검증 후 확정
