# PR-05: UI 입력 필드 예정 목록(초안)

## 목적
- 화면별 입력 항목을 미리 정리해 설계/개발 간 누락을 방지한다.
- 추후 상세 설계와 검증 기준의 기초 자료로 활용한다.

## 공통
- 로그인: 아이디, 비밀번호
- 암호변경: 현재 비밀번호, 신규 비밀번호, 비밀번호 확인

## 대시보드
- 생산현황: 조회 기간(시작/종료)
- 일정달력: 일정명, 시작일, 종료일, 비고

## 생산관리
- 수주현황: 조회 기간, 거래처
- 수주내역: 수주번호, 거래처, 품목, 수량
- 납품/반품: 납품일/반품일, 수량, 사유
- 작업관리: 작업번호, 품목, 공정, 수량
- 작업지시: 지시번호, 일정, 담당자

## 기준정보
- 품목: 품목코드, 품목명, 규격
- 품목유형: 유형코드, 유형명
- 작업공정: 공정코드, 공정명

## 재고관리
- 재고현황: 조회 창고, 품목
- 입고내역: 입고일, 품목, 수량
- 출고내역: 출고일, 품목, 수량
- 소요산출: 기준 기간, 품목

## 품질관리
- 불량현황: 조회 기간, 품목
- 불량내역: 불량유형, 수량, 발생일
- 불량유형: 유형코드, 유형명

## 설비관리
- 설비현황: 조회 기간, 설비
- 모니터링: 설비, 기간
- 설비등록: 설비코드, 설비명, 위치

## 시스템관리
- 사용자: 사용자ID, 이름, 권한
- 권한: 역할명, 권한목록
- 업무담당자: 업무코드, 담당자
- 거래처: 거래처명, 담당자, 연락처
- 공장/창고: 구분, 명칭, 위치
- KPI 관리: KPI명, 목표값, 산식, 단위
