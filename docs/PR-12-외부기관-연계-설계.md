# PR-12: 외부기관 API 연계 설계(초안)

## 목적
- 소상공인별 데이터를 외부기관에 자동 전송하는 흐름을 정의한다.
## 로드맵 반영
- PR-12 단계에서 연계 정책을 확정하고 적용한다.

## 연계 흐름
1) MES Web에서 전송 대상 데이터 집계
2) 마스킹/암호화 적용
3) 연계 API 호출
4) 실패 시 재시도/로그 기록

## 정책
- 연계 API는 추후 확정
- 실패 재시도 횟수/주기 정책 필요
- 증빙 로그는 PASS/FAIL 라인으로 기록

## 에러/재시도/증빙 정책(초안)
- 전송 실패 시 최대 3회 재시도(지수 백오프)
- 최종 실패 시 별도 재처리 큐로 이동
- 성공/실패 이력은 감사 로그로 보관

## 예외/오류 코드 표준(초안)
- EXT-400: 잘못된 요청(필수 값 누락)
- EXT-401: 인증 실패
- EXT-403: 권한 없음
- EXT-429: 전송 제한(요청 과다)
- EXT-500: 외부기관 시스템 오류
