# PR-12: 외부기관 연계 스모크 기준(초안)

## PASS 기준
- 전송 성공 시 [PASS] 라인 출력
- 전송 실패 시 [FAIL] 라인 출력

## SKIP 기준
- 외부기관 연계 API 미확정 또는 미구성 시 [SKIP] 라인 출력

## 출력 예시
- [PASS] external sync
- [FAIL] external sync
- [SKIP] external sync

## 스크립트 위치
- Windows: `scripts/smoke-external-sync.ps1`
- Linux: `scripts/smoke-external-sync.sh`
