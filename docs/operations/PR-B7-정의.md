# PR-B7 범위/목표/스모크 기준(미들웨어)

## 1) 작업 목표
- 격리 재처리 재시도 정책을 정의한다.
- 실패 사유를 표준 코드로 정리한다.

## 2) 작업 범위
- 재시도 가능 조건(횟수/간격/상태) 정의
- 재시도 실패 사유 코드 체계 확정
- 실패 사유 기록 흐름 연결

## 3) 스모크 기준
- 스모크 대상: 재시도 정책 흐름 1회 실행
- 스모크 결과 라인:
  - [PASS] middleware quarantine retry smoke ok
- 실행 불가 시:
  - [SKIP] middleware quarantine retry smoke: <사유>

## 4) 완료 기준(코드+스모크+문서)
- 코드: 재시도 정책과 실패 사유 기록 연결 완료
- 스모크: PASS 또는 SKIP 근거 1줄 기록
- 문서: 본 문서 업데이트 + 증빙 라인 기록

## 5) 증빙 기록 위치
