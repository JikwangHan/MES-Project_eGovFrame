# PR-11: 정규화 스키마(초안)

## 목적
- 다양한 입력 데이터를 공통 구조로 저장해 조회/분석을 단순화한다.

## 테이블(초안)
### normalized_event
- id: 정규화 이벤트 식별자
- source_id: 원본(raw) 식별자
- device_hint: 장비 후보(미확정 시 UNKNOWN)
- protocol_hint: 프로토콜 후보(미확정 시 UNKNOWN)
- event_type: 이벤트 유형(상태/측정/알람 등)
- event_time: 이벤트 시각(원본 기준)
- payload_json: 정규화된 JSON 본문
- confidence: 분류 신뢰도(0~1)
- created_at: 저장 시각

### raw_event
- id: 원본 식별자
- payload: 원본 문자열/바이너리(문자열 저장)
- received_at: 수신 시각
- source_ip: 수신 경로 식별(민감정보 제외)

## 비고
- 실제 DB 스키마 확정 전까지는 문서 기준으로만 유지한다.
