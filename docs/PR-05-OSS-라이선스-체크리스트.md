# PR-05: OSS 라이선스 체크리스트(초안)

## 목적
- 무료 오픈소스 사용 원칙을 지키기 위해 라이선스를 사전 점검한다.
- 배포/운영 환경에서 법적 리스크를 최소화한다.

## 공통 체크 항목
- 라이선스 유형 확인(MIT, Apache-2.0, GPL-2.0 등)
- 상용/유료 기능 분리 여부 확인
- 소스코드 공개 의무 여부 확인
- 특허/상표 조항 확인
- 공지/저작권 표기 요구사항 확인

## 후보별 1차 점검

| 항목 | 라이선스 | 상용판 구분 | 공개 의무 | 비고 |
| --- | --- | --- | --- | --- |
| MariaDB | GPL-2.0 | 없음 | 있음 | 서버 배포 방식 검토 필요 |
| Tabulator | MIT | 없음 | 없음 | 가벼운 그리드 |
| Apache ECharts | Apache-2.0 | 없음 | 없음 | 특허 조항 포함 |
| Bootstrap | MIT | 없음 | 없음 | 레이아웃 기본 |

## 결정 규칙
- 라이선스가 불명확하면 후보에서 제외한다.
- GPL 계열은 배포 방식과 영향 범위를 별도 검토 후 승인한다.
