# PR-18: 외부기관 연계 API 초안

## 목적
- 소상공인별 수집 데이터를 외부기관으로 자동 연계하기 위한 API 초안을 정리한다.

## 전제
- 연계 API 상세 스펙은 추후 확정
- 민감정보는 문서에 기록하지 않음

## 초안 엔드포인트
- POST /api/external-sync

## 요청 바디(예시)
```json
{
  "companyId": "C-001",
  "from": "2025-01-01",
  "to": "2025-01-31"
}
```

## 규칙(초안)
- from/to는 함께 제공해야 함
- 둘 다 비어 있으면 전체 기간으로 간주

## 응답(예시)
```json
{
  "result": "OK",
  "message": "",
  "data": {
    "requestId": "SYNC-20250101-0001",
    "status": "ACCEPTED",
    "acceptedAt": "2025-01-01T09:00:00"
  }
}
```

## 비고
- 실제 전송 방식은 외부기관 스펙 확정 후 결정
