# 서비스별 Chat 운영 규칙

## 공통 Chat(기준 관리)
- 공통 기준/계약/검증 규칙만 확정
- 변경 요청은 이 Chat에서만 승인
- 산출물: COMMON_STANDARDS.md 유지

## 서비스별 Chat(개발 실행)
- 해당 서비스 코드/문서만 수정
- 공통 기준 변경 필요 시 공통 Chat에 요청
- 스모크/문서 증빙은 PR 단위로 완료

## 충돌 방지
- 동일 파일은 한 Chat에서만 수정
- 공통 문서 수정은 공통 Chat 단독 수행

## 범위 밖 변경 처리 절차
1) 범위 밖 변경 발견 시 즉시 작업 중단
2) 변경 목록을 공통 Chat에 요청 형식으로 전달
3) 공통 Chat에서 서비스별로 분리(브랜치/파일 정리)
4) 분리 완료 후 해당 서비스 Chat 작업 재개
