# PR-11: 분류 기준표(초안)

## 목적
- 입력 데이터의 형태를 빠르게 분류하여 파싱/정규화 경로를 선택한다.

## 분류 기준(초안)
- text: 사람이 읽을 수 있는 텍스트(개행/구분자 포함)
- json: JSON 구조(중괄호/대괄호 기반)
- csv: 구분자 기반(쉼표/세미콜론/탭)
- binary: 사람이 읽기 어려운 이진 데이터(제어 문자 다수)
- unknown: 위 기준에 해당하지 않음

## 판별 규칙(초안)
- 입력 전체를 문자열로 확보한 뒤 길이/인쇄 가능 비율로 1차 분류
- JSON 시도 → 성공이면 json
- CSV 구분자 밀도/라인 수 기준으로 csv
- 인쇄 가능 비율이 낮으면 binary
- 나머지는 text

## 비고
- 이 기준은 프로토콜 확정 시 장비별로 보정한다.
