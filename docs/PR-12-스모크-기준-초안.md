# PR-12: 스모크 기준(초안)

## PASS 기준
- (검증) 입력 데이터 1건 이상이 검증 규칙을 통과한다.
- (격리) 검증 실패 데이터가 1건 이상 격리된다.
- (표준 로그) [PASS]/[SKIP] 라인이 출력된다.

## FAIL 기준
- 검증 파이프라인 기동 실패
- 검증 결과 미기록

## SKIP 기준
- 학습 데이터/승인 절차 미확정 시 [SKIP]

## 스모크 스크립트(예정)
- scripts/smoke-ai-validate.ps1
- scripts/smoke-ai-validate.sh

## 최근 실행 결과
- [PASS] ai validate smoke
- [PASS] ai validate smoke (재검증)
