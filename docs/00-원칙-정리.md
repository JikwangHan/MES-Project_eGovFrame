# 원칙 정리

## 목표
- 기존 MES-System(Node 기반)의 서비스 기능/운영 증빙을 100% 유지
- 전자정부표준프레임워크(eGovFrame) 기반으로 신규 구축

## 필수 원칙
1) 코드를 포팅하지 않고 계약과 테스트를 이식
2) 개발/실행/운영 환경은 모두 eGovFrame 기반
3) JDK 17 + Tomcat 9 기준 스캐폴딩
4) PR-00~PR-03 순서로 리스크 최소화
5) 모든 로그는 [PASS]/[FAIL]/[SKIP] 표준 라인으로만 핵심 근거 출력
6) 민감정보는 로그/문서에 기록하지 않음
7) 각 PR은 코드 + 스모크(또는 테스트) + 문서 증빙을 함께 갱신
