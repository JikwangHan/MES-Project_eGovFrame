# PR-05: UI 화면 체크리스트(초안)

## 목적
- UI/UX 문서의 모든 화면을 누락 없이 스캐폴딩하기 위한 목록이다.
- 실제 화면 수/이름은 문서 기준으로 최종 확정한다.

## 사용 방법
1) UI/UX 문서에서 화면 ID, 화면명, 메뉴 경로를 추출한다.
2) 아래 표에 추가하고, 스캐폴딩이 끝나면 상태를 갱신한다.
3) 신규 화면이 생기면 본 표에 먼저 반영한다.
