# 서비스별 Chat 운영 시작 가이드

## 목적
- 서비스별 Chat을 즉시 시작할 수 있도록 초기 절차를 안내한다.

## 시작 순서
1) 공통 Chat에서 최신 `COMMON_STANDARDS.md` 확인
2) 서비스별 Chat에 적용 범위를 알림
3) PR 단위로 “기능 + 스모크 + 문서” 완료

## 서비스별 Chat 예시
- Chat-A: IoT 인터페이스(Edge Gateway)
- Chat-B: AI 미들웨어
- Chat-C: MES Web 서비스

## 공통 Chat 운영
- 기준 변경 요청은 공통 Chat에서만 확정
- 확정 후 각 서비스 Chat에 변경 사항 전달
