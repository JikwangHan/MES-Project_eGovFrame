# PR-B4 범위/목표/스모크 기준(미들웨어)

## 1) 작업 목표
- 격리(Quarantine) 처리 흐름을 코드로 구현한다.
- 격리 대상의 저장/조회 기준을 최소 수준으로 확정한다.

## 2) 작업 범위
- 격리 판정 조건(룰/임계치/검증 실패)을 코드 기준으로 연결
- QuarantineStore 저장 흐름 연결
- 격리 이벤트 기본 구조(시간/원인/요약) 기록

## 3) 스모크 기준
- 스모크 대상: 격리 처리 흐름 1회 실행
- 스모크 결과 라인:
  - [PASS] middleware quarantine smoke ok
- 실행 불가 시:
  - [SKIP] middleware quarantine smoke: <사유>

## 4) 완료 기준(코드+스모크+문서)
- 코드: 격리 처리 흐름이 동작하도록 연결 완료
- 스모크: PASS 또는 SKIP 근거 1줄 기록
- 문서: 본 문서 업데이트 + 증빙 라인 기록
