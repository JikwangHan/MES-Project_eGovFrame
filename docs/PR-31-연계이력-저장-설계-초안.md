# PR-31: 외부기관 연계 요청 이력 저장 설계(초안)

## 목적
- 외부기관 연계 요청/응답 이력을 추적할 수 있도록 저장 구조를 정의한다.
- 실제 DB 반영 전, 설계 기준만 먼저 확정한다.

## 전제
- 외부기관 API 스펙은 미확정 상태
- 민감정보는 기록하지 않음

## 저장 대상(핵심 필드)
- request_id: 연계 요청 식별자
- company_id: 회사 식별자(선택)
- from_date: 요청 시작일(선택)
- to_date: 요청 종료일(선택)
- status: 요청 처리 상태(예: ACCEPTED, FAILED)
- accepted_at: 요청 접수 시간
- error_code: 실패 코드(선택)
- error_message: 실패 메시지(선택)
- raw_request: 원시 요청 본문(문자열)
- raw_response: 원시 응답 본문(문자열)
- created_at: 생성 시간
- updated_at: 수정 시간

## 보관 정책(초안)
- 원시 로그는 최소 N일 보관(기간은 운영 정책 확정 후 결정)
- 샘플/개발 환경에서는 30일 보관을 기본값으로 가정

## 확장 고려
- 추후 외부기관별 endpoint 구분 컬럼 추가 가능
- 재전송 횟수/최종 전송 시간 컬럼 추가 가능
