# 서명 및 정규화 규칙 (초안)

이 문서는 게이트웨이 업링크 서명 규칙과 정규화 규칙을 고정하기 위한 초안입니다.

## 1) 서명 규칙
- 목적: 위변조 방지
- 입력: companyId, deviceId, timestamp, nonce, payload
- 결과: signature
- 서버는 동일한 규칙으로 서명을 재계산하여 검증한다.
- 서명 입력 규칙은 프로토콜 정의서에서 최종 확정한다.

## 2) 정규화 규칙
- 장비별 원시 데이터를 표준 telemetry 모델로 변환한다.
- 표준 필드(예시):
  - deviceId
  - timestamp
  - status
  - metrics (키-값)

## 3) 프로토콜 정의서 연계
- IoT 인터페이스 연동과 제조장비 직접 연동 모두 프로토콜 정의서를 따른다.
- 프로토콜은 변경 가능하며, 다수의 프로토콜을 지원할 수 있다.

## 4) 타임스탬프 기준
- 서버 수신 시각이 아닌 장비 기준 시각을 우선한다.
- 허용 오차 범위를 설정하고, 초과 시 실패로 처리한다.
