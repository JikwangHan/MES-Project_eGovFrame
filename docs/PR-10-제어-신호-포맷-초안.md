# PR-10: 제어 신호 공통 포맷(초안)

## 목적
- 프로토콜이 확정되기 전에도 공통 구조로 제어 요청을 표현한다.

## 기본 구조(초안)
- command: 제어 명령(예: START/STOP/PAUSE/RESUME)
- target: 대상 장비 식별자(미확정 시 "DEVICE-UNKNOWN")
- requestedAt: 요청 시각(ISO-8601)
- params: 추가 파라미터(선택)

## 샘플
```json
{
  "command": "START",
  "target": "DEVICE-UNKNOWN",
  "requestedAt": "2025-01-01T00:00:00Z",
  "params": {
    "speed": "N/A"
  }
}
```

## 비고
- 실장비 프로토콜 확정 시 전용 필드를 확장한다.
