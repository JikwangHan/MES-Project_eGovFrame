# PR-08: 필터 입력 검증 시나리오(초안)

## 목적
- 필터 입력값 오류에 대한 화면 반응을 확인한다.

## 시나리오
1) 수주 화면에서 `납기일 시작`에 `2025/12/01` 입력  
   - 기대: 납기일 형식 오류 표시 + 조회 버튼 비활성화

2) 수주 화면에서 `상태`에 `DONE` 외 임의값 입력  
   - 기대: 수주 상태 오류 표시 + 조회 버튼 비활성화

3) 작업 화면에서 `기간 시작`에 `20251201` 입력  
   - 기대: 작업 기간 형식 오류 표시 + 조회 버튼 비활성화

4) KPI 화면에서 `기간 종료`에 `2025-13-01` 입력  
   - 기대: KPI 기간 형식 오류 표시(형식 기준 우선) + 조회 버튼 비활성화

5) 수주 화면에서 `납기일 시작`을 `2025-12-31`, `납기일 종료`를 `2025-12-01` 입력  
   - 기대: 납기일 기간 역전 경고 표시 + 조회 버튼 비활성화

6) KPI 화면에서 `기간 시작`을 `2025-12-31`, `기간 종료`를 `2025-12-01` 입력  
   - 기대: KPI 기간 역전 경고 표시 + 조회 버튼 비활성화

7) KPI 화면에서 `기간 종료`에 `2025-13-01` 입력  
   - 기대: KPI 유효하지 않은 월 경고 표시 + 조회 버튼 비활성화

8) 수주 화면에서 `납기일 시작`에 `2025-02-30` 입력  
   - 기대: 납기일 유효하지 않은 일 경고 표시 + 조회 버튼 비활성화

9) 잘못된 입력을 정상 값으로 수정  
   - 기대: 경고 문구와 붉은 테두리가 제거되고 조회 버튼이 활성화

10) 모든 필터를 비워둔 상태  
   - 기대: 전체 조회 안내 문구가 표시됨

11) 필터 입력 후 조회  
   - 기대: 최근 조회 조건 요약이 표시됨(예: orderId=ORD-001, status=DONE)

## 비고
- 날짜 형식과 유효 날짜(월/일 범위) 검증을 포함한다.
