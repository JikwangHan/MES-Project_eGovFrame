# PR-07: AI 미들웨어 P1 상세 설계(초안)

## 입력
- 원본 데이터(바이너리/텍스트)
- 메타 정보(수신 채널, 시간, 송신지)

## 처리 단계
1) 시그니처 룰 매칭
2) ML 분류로 프로토콜 후보 추정
3) LLM 보조로 설명/근거 생성
4) 신뢰도 기준에 따라 정규화 또는 Quarantine

## 출력
- 정규화 데이터
- 판단 근거/신뢰도

## 신뢰도 기준(초안)
- 0.8 이상: 자동 정규화
- 0.5 이상 0.8 미만: 보류 후 검토
- 0.5 미만: Quarantine

## 운영 처리(초안)
- 자동 정규화: 알림 로그만 기록
- 보류 후 검토: 담당자 승인 필요
- Quarantine: 관리자 알림 및 재분류 대기
