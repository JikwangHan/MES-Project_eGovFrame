# PR-03 게이트웨이 설계

## 목표
- 제조장비 데이터를 시뮬레이터 기준으로 읽고 정규화해 MES Web으로 업링크한다.
- PR-02의 최소 API(`/api/uplink`)를 기준으로 연동한다.

## 범위
- 시뮬레이터 입력(JSON) -> 정규화 -> 업링크
- 실패 시 [FAIL] 라인으로 종료
- 원본 데이터는 별도 보관(향후 AI 파이프라인과 연결)

## 실행 흐름(초안)
1) 샘플 데이터 로딩
2) 업링크 전송
3) 201 응답 확인

## 스모크
- Windows: `scripts/smoke-gateway.ps1`
- Linux/macOS: `scripts/smoke-gateway.sh`

## 검증 기준
- 스모크 실행 결과가 [PASS] 1줄을 출력한다.
