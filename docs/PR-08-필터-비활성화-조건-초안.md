# PR-08: 필터 조회 버튼 비활성화 조건(초안)

## 목적
- 잘못된 입력값으로 조회 요청이 발생하지 않도록 한다.

## 공통 규칙(초안)
- 유효성 오류가 있으면 조회 버튼을 비활성화한다.
- 오류가 해소되면 즉시 활성화한다.
- 최근 조회 조건 요약은 12자 초과 시 "...\"로 축약 표시한다.

## 화면별 조건(초안)
### 수주 화면
- 납기일 시작/종료가 YYYY-MM-DD 형식이 아니면 비활성화
- 상태 값이 PLANNED/IN_PROGRESS/DONE 이 아니면 비활성화
- 유효하지 않은 입력이 있으면 해당 입력칸을 붉은 테두리로 강조

### 작업 화면
- 기간 시작/종료가 YYYY-MM-DD 형식이 아니면 비활성화
- 상태 값이 PLANNED/IN_PROGRESS/DONE 이 아니면 비활성화
- 유효하지 않은 입력이 있으면 해당 입력칸을 붉은 테두리로 강조

### KPI 화면
- 기간 시작/종료가 YYYY-MM-DD 형식이 아니면 비활성화
- 유효하지 않은 입력이 있으면 해당 입력칸을 붉은 테두리로 강조
