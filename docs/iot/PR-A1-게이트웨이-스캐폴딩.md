# PR-A1 IoT 인터페이스 스캐폴딩

## 목표
- 업링크/다운링크 기본 흐름을 구성해 이후 단계 확장 기반을 마련한다.
- 실패/스킵 처리 기준을 고정해 운영 증빙을 일관되게 한다.

## 범위
- 업링크: 입력 로딩 -> 정규화(현재는 통과 처리) -> 전송(201 응답 확인)
- 다운링크: 명령 조회 -> (옵션) 파일 저장
- 로그: PASS/FAIL/SKIP 라인만 출력

## 실행 옵션(요약)
- `--mode` : uplink | downlink | both
- `--uplink-url` / `--downlink-url` : 대상 엔드포인트 설정
- `--input` / `--stdin` : 업링크 입력 소스 선택
- `--downlink-output` : 다운링크 응답 저장 경로(옵션)
- `--timeout` : 네트워크 타임아웃(초)

## 스모크 기준
- 업링크 201 응답 시 [PASS] 1줄 출력
- 다운링크 204 응답은 [SKIP], 200 응답은 [PASS]
