# PR-08: 필터/검색 조건 UI 초안

## 목적
- 화면별 필터/검색 항목을 미리 합의해 데이터 바인딩 기준을 안정화한다.

## 공통 규칙(초안)
- 기간 필터는 from/to 형식(YYYY-MM-DD)으로 통일한다.
- 검색 버튼은 1개, 초기화 버튼은 선택 사항으로 둔다.
- 필수 입력은 최소화하고, 미입력 시 전체 조회로 처리한다.

## 화면별 필터(초안)
### 대시보드
- 기간(from/to)
- 설비 상태(선택: OK/WARNING/NEVER)

### 설비현황
- 설비 상태(OK/WARNING/NEVER)
- 설비 ID(부분 일치)

### 수주
- 수주번호
- 거래처명
- 납기일 기간(from/to)
- 상태(PLANNED/IN_PROGRESS/DONE)

### 작업
- 작업 ID
- 수주번호
- 공정명
- 기간(from/to)
- 상태(PLANNED/IN_PROGRESS/DONE)

### KPI
- KPI명
- 기간(from/to)
- KPI ID(선택)

## 비고
- 실제 필터 항목은 데이터 모델 확정 후 변경될 수 있다.
