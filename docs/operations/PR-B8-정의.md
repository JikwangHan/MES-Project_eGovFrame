# PR-B8 범위/목표/스모크 기준(미들웨어)

## 1) 작업 목표
- 격리 재처리 우선순위를 정의한다.
- 일괄 재처리 흐름을 최소 단위로 구현한다.

## 2) 작업 범위
- 우선순위 기준(중요도/오류 유형/시간) 정의
- 일괄 재처리 요청 흐름(선택/실행/결과 기록) 연결
- 일괄 처리 결과 요약(성공/실패 건수) 기록

## 3) 스모크 기준
- 스모크 대상: 일괄 재처리 흐름 1회 실행
- 스모크 결과 라인:
  - [PASS] middleware quarantine batch smoke ok
- 실행 불가 시:
  - [SKIP] middleware quarantine batch smoke: <사유>

## 4) 완료 기준(코드+스모크+문서)
- 코드: 우선순위 + 일괄 처리 흐름 연결 완료
- 스모크: PASS 또는 SKIP 근거 1줄 기록
- 문서: 본 문서 업데이트 + 증빙 라인 기록
