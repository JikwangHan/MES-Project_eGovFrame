# PR-05: UI 권한 기준 예정 목록(초안)

## 목적
- 화면별 접근 권한 기준을 사전 정리한다.
- 역할 기반 인가 정책의 기준 문서로 활용한다.

## 공통
- 로그인/암호변경: 모든 사용자 접근 가능

## 대시보드
- 생산현황/일정달력: 일반 사용자 이상

## 생산관리
- 수주/작업/작업지시: 생산 담당자 이상

## 기준정보
- 품목/품목유형/작업공정: 관리자 또는 기준정보 담당자

## 재고관리
- 재고/입출고/소요산출: 재고 담당자 이상

## 품질관리
- 불량현황/내역/유형: 품질 담당자 이상

## 설비관리
- 설비현황/모니터링/설비등록: 설비 담당자 이상

## 시스템관리
- 사용자/권한/업무담당자/거래처/공장창고: 관리자 전용

## 비고
- 실제 권한 매핑은 역할 정의서 확정 후 반영한다.
