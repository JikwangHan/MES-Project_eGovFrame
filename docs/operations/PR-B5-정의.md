# PR-B5 범위/목표/스모크 기준(미들웨어)

## 1) 작업 목표
- 격리(Quarantine) 데이터의 재처리 흐름을 정의한다.
- 재처리 이력을 남길 수 있는 최소 구조를 확정한다.

## 2) 작업 범위
- 재처리 대상 조회 기준(기간/상태/사유) 정의
- 재처리 요청 흐름(선택/재처리/결과 기록) 연결
- 재처리 결과 이력(시간/결과/요약) 기록

## 3) 스모크 기준
- 스모크 대상: 격리 데이터 재처리 흐름 1회 실행
- 스모크 결과 라인:
  - [PASS] middleware quarantine reprocess smoke ok
- 실행 불가 시:
  - [SKIP] middleware quarantine reprocess smoke: <사유>

## 4) 완료 기준(코드+스모크+문서)
- 코드: 재처리 흐름과 이력 기록이 연결되어야 함
- 스모크: PASS 또는 SKIP 근거 1줄 기록
- 문서: 본 문서 업데이트 + 증빙 라인 기록

## 5) 증빙 기록 위치
