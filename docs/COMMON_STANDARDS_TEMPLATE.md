# 서비스별 Chat 공통 기준 문서 템플릿

## 문서 목적
- 서비스별 개발 Chat에서 공통으로 따라야 할 기준을 정의한다.
- 기준 변경 시 전체 서비스에 동일하게 반영한다.

## 적용 범위
- IoT 인터페이스(Edge Gateway)
- AI 미들웨어
- MES Web 서비스

## 공통 원칙
- PASS/FAIL/SKIP 로그 라인만 출력
- 민감정보(경로/계정/토큰/내부 커밋 해시) 문서/로그에 금지
- PR은 “코드 + 스모크(또는 테스트) + 문서” 동시 갱신

## 공통 계약(초안)
- API 경로/메서드: [정의 필요]
- 요청/응답 포맷: [정의 필요]
- 에러코드 규칙: [정의 필요]

## 공통 검증 규칙(초안)
- 날짜 형식: YYYY-MM-DD
- 기간 역전 금지(from > to)
- 상태 코드: [정의 필요]

## 스모크 기준(초안)
- 서비스 기동 확인: /health 200
- 핵심 API 1개 이상 PASS

## 변경 절차
- 변경 요청 → 공통 Chat 승인 → 각 서비스에 반영

## 비고
- 이 템플릿은 공통 Chat에서만 수정한다.
