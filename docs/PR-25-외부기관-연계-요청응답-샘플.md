# PR-25: 외부기관 연계 요청/응답 샘플(초안)

## 목적
- 외부기관 연계 API의 요청/응답 예시를 별도로 관리한다.
- 실제 스펙 확정 전까지 참고용으로만 사용한다.

## 요청 샘플(기본)
```json
{
  "companyId": "C-001",
  "from": "2025-01-01",
  "to": "2025-01-31"
}
```

## 응답 샘플(기본)
```json
{
  "result": "OK",
  "message": "",
  "data": {
    "requestId": "SYNC-20250101-0001",
    "status": "ACCEPTED",
    "acceptedAt": "2025-01-01T09:00:00"
  }
}
```

## 규칙 요약
- from/to는 함께 제공해야 한다.
- 둘 다 비어 있으면 전체 기간으로 간주한다.
