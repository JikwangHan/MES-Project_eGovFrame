# PR-15: 화면별 필드/검증 규칙(초안)

## 공통 규칙
- 필수값 누락 시 저장 불가
- 문자열은 앞/뒤 공백 제거
- 상태/유형은 code 테이블 기준값만 허용

## 장비(Equipment)
- device_code: 필수, 64자 이하
- name: 필수, 100자 이하
- model: 선택, 100자 이하
- vendor: 선택, 100자 이하
- status: 필수, 기본값 ACTIVE

## 수주(Order)
- order_no: 필수, 64자 이하
- partner_name: 선택, 100자 이하
- due_date: 선택, YYYY-MM-DD
- status: 필수, 기본값 PLANNED

## 작업(Job)
- order_id: 필수
- process_name: 필수, 100자 이하
- start_time: 선택, YYYY-MM-DD HH:MM:SS
- end_time: 선택, YYYY-MM-DD HH:MM:SS
- status: 필수, 기본값 PLANNED

## KPI
- name: 필수, 100자 이하
- target_value: 선택, 숫자
- current_value: 선택, 숫자
- unit: 선택, 32자 이하
- formula: 선택, 200자 이하
