# PR-10: 착수 준비(초안)

## 목적
- 미들웨어에서 제조장비(또는 IoT 인터페이스)로 제어 신호를 송신하는 1차 흐름을 정의한다.

## 범위(초안)
- 프로토콜 미확정 상태에서도 사용할 수 있는 공통 송신 포맷을 정의한다.
- 송신 결과를 표준 로그([PASS]/[FAIL]/[SKIP])로 남긴다.
 - 모의 송신을 통해 최소 송신 흐름을 확인한다.

## 전제 조건(확정 필요)
- 제어 명령 종류(예: 시작/정지/속도 변경 등)와 우선순위를 정해야 한다.
- 실제 통신 프로토콜 확정 시 전용 어댑터를 추가해야 한다.

## 제외(초안)
- 실장비 제어 승인은 별도 운영 정책으로 분리한다.
